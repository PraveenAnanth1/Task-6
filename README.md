## 🤖 Task 6: K-Nearest Neighbors (KNN) Classification

### 📌 Objective

Learn and implement **KNN classification** using Scikit-learn, evaluate its accuracy, and visualize how it classifies data.

---

### 🛠️ Tools & Libraries

* Python
* Scikit-learn
* Pandas
* Matplotlib

---

### 📂 Dataset

* **Iris dataset** (built-in from Scikit-learn)
* We use only 2 features for easy 2D visualization.

---

### 📈 What This Project Does

1. **Loads the Iris dataset**
2. **Normalizes** the feature values using `StandardScaler`
3. **Splits** the data into training and testing sets
4. Trains **KNN classifiers** for different `K` values (e.g., K=1, 3, 5, 7)
5. **Evaluates accuracy** and shows a **confusion matrix** for each K
6. **Visualizes decision boundaries** to show how the KNN model classifies regions

---

### 📊 Output

* Accuracy for different values of K
* Confusion Matrix plots
* Decision Boundary plot for best K value
